# AI 生图提示词装配台（prompt-builder）

> 从词库挑要素、向导式装配生图提示词，成稿可直接复制使用。
> 纯本地单文件 HTML —— 双击即用，不上传任何数据。

![license](https://img.shields.io/badge/license-MIT-blue) ![single file](https://img.shields.io/badge/single--file-yes-brightgreen) ![dependencies](https://img.shields.io/badge/dependencies-0-brightgreen)

## 它是什么

一个 HTML 文件（`index.html`）：

- **按步骤装配**：画面主体 → 环境 → 光线 → 构图 → 风格 → 收尾，每步列出该步可用的要素
- **要素有状态**：常用 / 可用 / 少见 / 慎用 / 过时，慎用与过时会被折叠或提示
- **向导模式**：不想挑词就回答几个问题（画什么 / 画面里有什么 / 用在哪 / 什么感觉 / 不要出现什么），自动生成一稿
- **范例库**：按画面类型给真实范例，可直接套用改写
- **成稿区**：可撤销、可分享、可一键复制

## 怎么用

双击 `index.html`（Chrome / Edge 等现代浏览器）→ 按左栏步骤走，或点「向导」按钮。

## 隐私

纯前端：没有后端、没有统计、没有埋点；词库与你的选择都在本机，**不上传**。
